# DonTranQuiL-Thread-Feed

Shared thread feed configuration for DonTranQuiL projects.

## Files

- `global_blacklist.txt` lists entries that are always excluded from the feed, one per line.
- `global_whitelist.txt` lists entries that are always allowed in the feed, one per line.
